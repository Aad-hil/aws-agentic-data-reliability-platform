# Code of Conduct

## Our standard

We are committed to a welcoming, respectful, and constructive project environment. Participants should communicate professionally, assume good intent, and focus feedback on the work rather than individuals.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, or deliberately disruptive behavior are not acceptable.

## Reporting

Report concerns privately to the repository owner through the contact method listed on the repository profile. Please do not disclose security vulnerabilities in public issues; use the process in SECURITY.md.
