# Security Policy

## Supported versions

Only the default branch is considered actively maintained.

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected security vulnerability.

Report it privately to the repository owner through the contact information available on the GitHub profile. Include the affected component, reproduction steps, impact, and any relevant logs. Do not include credentials or other sensitive data.

## Secrets

Never commit AWS access keys, Bedrock credentials, tokens, `.env` files, or other secrets. Use AWS IAM roles and local environment configuration instead.
